# Blinkit Sales Performance Analysis

### A Deep Dive into Quick-Commerce Analytics using Python and Power BI

---

## 📋 Project Overview

This project presents a comprehensive analysis of sales data from **Blinkit**, a leading quick-commerce platform in India. The goal is to dissect sales patterns, identify key performance drivers, and provide actionable insights that could help in strategic decision-making.

The analysis follows a two-part workflow:
1.  **Exploratory Data Analysis (EDA)** performed using **Python** in a Jupyter Notebook to clean the data, understand its structure, and uncover initial trends.
2.  An **Interactive Dashboard** built in **Power BI** to visualize the findings and create a dynamic tool for business monitoring.

This repository contains both the Python EDA notebook and screenshots of the final Power BI dashboard.

---

## 📊 Dashboard & Key Insights

The Power BI dashboard provides a holistic view of the sales performance, focusing on key metrics and dimensions.

### Main KPIs:
* **Total Sales:** $1.20M
* **Total Items Sold:** 8.52K
* **Average Sales:** $141
* **Average Item Rating:** 3.9


### Key Findings:
* **Outlet Performance:** The analysis revealed that **Medium-sized** outlets are the primary revenue drivers, significantly outperforming Small and Large outlets. Geographically, outlets in **Tier 1** city locations generate the highest sales.
* **Product Category Insights:** **"Fruits and Vegetables"** and **"Snack Foods"** emerged as the top-performing item categories, highlighting their importance to the business's bottom line.
* **Sales Trends:** The **"Outlet Establishment"** chart shows a significant peak in business growth and sales around the year **2018**.

## 🛠️ Technical Workflow & Methodology

This project was executed in two distinct phases to ensure a thorough and robust analysis.

### 1. Exploratory Data Analysis (Python)
The initial phase involved using Python's data science libraries (Pandas, Matplotlib, Seaborn) to perform a deep dive into the raw dataset. Key steps included:
* Data Loading and Initial Inspection
* Data Cleaning (handling missing values, correcting data types)
* Univariate and Bivariate Analysis
* Identifying patterns and correlations between different features.

The complete EDA process is documented in the Jupyter Notebook available in this repository.
* **[Access the EDA Notebook here](./blinkit_eda.ipynb)**

### 2. Dashboard Development (Power BI)
After cleaning and exploring the data, I used Power BI to build an intuitive and interactive dashboard. The steps included:
* Importing the cleaned dataset into Power BI.
* Creating a data model and defining relationships.
* Developing DAX measures to calculate key metrics like Total Sales, Average Sales, etc.
* Designing a visually appealing and user-friendly interface with slicers for dynamic filtering by Outlet Location, Size, and Item Type.
